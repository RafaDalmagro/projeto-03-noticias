# 📰 Desafio: Página de Notícias com CSS Grid

Este projeto faz parte da trilha de estudos de CSS da Rocketseat e tem como objetivo principal aplicar **CSS Grid** na construção de um layout moderno e organizado para uma **página de notícias**. A proposta é praticar o posicionamento de elementos em grade, criando seções bem estruturadas e visualmente agradáveis.

## 🧾 Descrição do Desafio

A ideia central é desenvolver uma página que simule um portal de notícias, utilizando o poder do **CSS Grid** para organizar:

- 🧱 Cabeçalho com menu de navegação;
- 🧭 Barra lateral (sidebar) com destaques ou categorias;
- 📰 Área principal com cards de notícias;
- 📬 Rodapé com informações adicionais.

## 🧠 O que foi praticado

Durante o desenvolvimento, foram aplicados os seguintes conceitos:

- ✅ **CSS Grid Layout** para estruturar a página em colunas e linhas;
- ✅ **Grid Template Areas** para posicionamento semântico;
- ✅ **Responsividade com Grid** para adaptação em diferentes larguras de tela;
- ✅ Organização semântica com HTML5.

## 🔧 Tecnologias Utilizadas

- HTML5
- CSS3 (foco em Grid)
- Figma (como referência visual)

## 🎯 Objetivo

Compreender a estrutura e flexibilidade do **CSS Grid**, construindo uma página com layout consistente, limpo e facilmente adaptável. Este desafio reforça a importância de **separar conteúdo de apresentação** e usar a semântica a favor da acessibilidade e manutenção do projeto.

## 📌 Obs: Este projeto foi desenvolvido com fins educacionais, como parte do aprendizado de layout moderno com CSS Grid.
